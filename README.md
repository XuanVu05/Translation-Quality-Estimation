# Translation Quality Estimation

## Project structure

- `mqm_newstest2020_ende.tsv`: Source MQM dataset.
- `src/`: Main data preparation, splitting, training, evaluation and validation scripts.
- `analysis/`: Data quality and error analysis scripts.
- `experiments/`: Additional experiments and case inspection.
- `archive_scripts/`: Older diagnostic scripts retained for reproducibility.
- `results/week10/`: Week 10 experimental outputs.

## Reproducibility

- Keep the original dataset unchanged.
- Preserve generated results, logs and configuration details.
- Run scripts from the project root unless their instructions specify otherwise.
- Update script paths after reorganizing files.
